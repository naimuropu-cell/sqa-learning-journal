# Postman Automation Test Scripts

## Introduction

Postman Test Scripts allow QA engineers to write JavaScript code that automatically validates API responses after sending requests.

Instead of manually checking every response, test scripts help automate API validation and improve testing efficiency.

Postman uses JavaScript in the **Tests** tab to create automated checks.

---

# Why Use Postman Test Scripts?

Manual API testing requires checking every response by yourself.

For example:

* Is the status code correct?
* Is the response time acceptable?
* Does the response contain required data?
* Is the returned value correct?

Postman scripts can automatically verify these conditions.

---

# Basic Test Script Structure

Example:

```javascript
pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});
```

### Explanation:

* `pm.test()` → Creates a test case
* `"Status code is 200"` → Test name
* `pm.response` → Accesses API response
* `to.have.status(200)` → Checks HTTP status code

---

# Common Postman Test Scripts

## 1. Verify Status Code

```javascript
pm.test("Status code should be 200", function () {
    pm.response.to.have.status(200);
});
```

Purpose:

Checks whether API request was successful.

---

## 2. Verify Response Contains Data

Example API Response:

```json
{
    "name": "John",
    "email": "john@test.com"
}
```

Test:

```javascript
pm.test("Response contains user name", function () {
    let response = pm.response.json();

    pm.expect(response.name).to.exist;
});
```

Purpose:

Checks whether the required field exists.

---

## 3. Verify Response Time

```javascript
pm.test("Response time should be less than 1000ms", function () {
    pm.expect(pm.response.responseTime)
        .to.be.below(1000);
});
```

Purpose:

Checks API performance.

---

## 4. Validate Response Data

Example:

```javascript
pm.test("User email is correct", function () {

    let response = pm.response.json();

    pm.expect(response.email)
    .to.eql("john@test.com");

});
```

Purpose:

Ensures API returns expected data.

---

# Using Variables in Tests

Example:

Save user ID from response:

```javascript
let response = pm.response.json();

pm.environment.set(
    "user_id",
    response.id
);
```

Now:

```
{{user_id}}
```

can be used in another request.

      ↓

Automation:

2. Script saves user ID.
